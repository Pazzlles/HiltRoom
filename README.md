## Тема приложения
Онлайн-приложение для просмотра постов из `JSONPlaceholder`.

## Какой API выбран
`JSONPlaceholder`  
<https://jsonplaceholder.typicode.com/posts>

API работает без ключа.

## Кратко суть
Приложение показывает список постов, позволяет фильтровать их по `userId` и открывать экран деталей выбранного поста.

Базой служит проект из ДЗ №3, а в рамках ДЗ №4 в него добавлены `Hilt` и `Room`.

## Что хранится в Room

Реализован сценарий: кэш нескольких уже загруженных запросов.

В `Room` сохраняются:
- `postId`
- `userId`
- `title`
- `body`
- строка запроса (`userId` или пустой запрос для общего списка)
- время обновления кэша

### Таблицы

- `cached_posts` — кэш постов по сохранённым запросам и для offline-detail
- `search_cache_metadata` — служебная информация о ранее сохранённых запросах

### Как работает сценарий

- при успешной загрузке данные приходят из сети и сохраняются в `Room`
- если сеть недоступна, приложение пытается показать кэш именно для того запроса, который уже загружался раньше
- экран деталей тоже может открыться из `Room`, если пост был сохранён ранее
- в интерфейсе показывается, откуда пришли данные: из сети или из `Room`
