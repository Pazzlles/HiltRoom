## Тема приложения
Онлайн-приложение для просмотра постов из 'JSONPlaceholder'.

## Какой API выбран
JSONPlaceholder (https://jsonplaceholder.typicode.com/posts, работает без ключа).

## Кратко суть
Приложение показывает список постов, позволяет фильтровать их по 'userId' и открывать экран деталей выбранного поста. 

Базой служит проект из ДЗ №3, а в рамках ДЗ №4 в него добавлены 'Hilt' и 'Room'.

## Что хранится в Room

Реализован сценарий: 'Cache последнего успешного результата поиска'.

В 'Room' сохраняются:
- postId;
- userId;
- title;
- body;
- строка последнего успешного поискового запроса;
- время последнего обновления кэша.

### Таблицы

- 'cached_posts' - кэш постов из последнего успешного запроса;
- 'search_cache_metadata' - служебная информация о последнем сохранённом запросе.

### Как работает сценарий

- при успешной загрузке списка данные приходят из сети и сохраняются в `Room`;
- если сеть недоступна, приложение пытается показать кэш именно для последнего успешного запроса;
- экран деталей тоже может открыть пост из `Room`, если этот пост уже есть в сохранённом кэше;
- в интерфейсе показывается, откуда пришли данные: из сети или из `Room`.
